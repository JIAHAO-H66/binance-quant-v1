事件顺序：

当前15M开盘：
执行上一根15M收盘产生的等待信号。

当前15M内部：

当前15M收盘：
检查趋势退出。
然后确认新的突破信号。

新的突破信号不会在当前K线立即成交。
它会进入下一根15M开盘的等待队列。

因此：
当前K线收盘产生信号 ↓
下一根K线开盘成交

不会使用下一根K线的收盘价决定入场。

止损优先于趋势退出。

趋势退出规则：
多单： 4H 转为空头方向时退出； 或者 1H 与 15M 同时转为空头时退出。

空单： 4H 转为多头方向时退出； 或者 1H 与 15M 同时转为多头时退出。

因此，单独15M EMA20 / EMA50反转， 不会立即强制平仓。 V2.9 与 V2.9 的核心区别： 入场从“趋势 + 直接突破”升级为“趋势 + 回调/回踩 + 重新转强/转弱 + 突破确认”。 这样可以减少连续追涨/追跌型信号，同时仍保持下一根15M开盘成交与无未来函数原则。 V2.9 在 V2.9 基础上进一步修正组合风险边界：入场名义采用1.75×权益的内部缓冲上限，并在组合达到2×前主动留出安全余量；同时提高突破实体、收盘位置和均线间距要求，并将过远结构止损上限收紧至2.6 ATR。
